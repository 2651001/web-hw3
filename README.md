## 어려웠던 점 3가지와 해결
1. **조건이 겹칠 때 필터·검색·정렬 상태 꼬임**: 검색어를 입력한 상태에서 정렬이나 보기 라디오를 바꾸면 앞선 조건이 빠지는 현상이 있었습니다. 검색, 보기 필터, 정렬을 `getView()` 한곳에서 `search → filter → sortBy` 순서로 처리하고 모든 변경 이벤트가 `refresh()`를 부르도록 통일해 해결했습니다.
2. **목록을 다시 그릴 때 찜 목록 유실**: 검색이나 정렬을 실행하면 카드 요소가 새로 만들어지면서 화면 클래스만으로 찜 여부를 기억하기 어려웠습니다. 찜한 영화 제목 배열 `liked`를 `localStorage`에 기록하고 그릴 때마다 `liked.includes(movie.title)`로 클래스를 다시 입혀 새로고침 뒤에도 유지되게 했습니다.
3. **하트 버튼 클릭 시 상세 모달까지 같이 열리는 문제**: 카드 전체에 클릭 이벤트 위임을 적용했더니 찜 버튼(`.like`)을 눌러도 상세 `<dialog>`가 함께 열렸습니다. `event.target.closest(".like")`로 찜 버튼을 먼저 처리한 뒤 `return`으로 빠져나오도록 순서를 잡았습니다.
